# Вторая схема: замена польского VPS через Node Host

Это отдельный способ восстановления: Cherry заменяет Floating IP, Node Host
заменяет весь VPS. Работающая Cherry-нода и её разрешения не используются для
покупки VPS. Новая схема пока не включена для автоматического восстановления.

## Согласованные параметры

- Польша, порт 10 Gbps, 1 vCPU, 3 ГБ RAM, диск 25 ГБ, Ubuntu 24.04, срок сутки.
- Управляемый домен этой схемы — только `pl.vetka.rest`.
- Исходный VPS выбирает владелец. Известные заблокированные IP сохраняются в БД;
  их нельзя устанавливать и публиковать в DNS при повторной выдаче.
- Новый кандидат загружается четыре минуты, затем Check-Host проверяет TCP 22
  из РФ (не менее двух ASN) и Германии, Нидерландов, Франции.
- Один timeout не отбрасывает IP: при доступных трёх зарубежных странах нужны
  три подозрительных RU-замера с интервалом не менее минуты. Неопределённый
  ответ оставляет VPS на повторной проверке. SSH не подтверждает MTProto.
- После подходящего IP следует DNS-переход, проверка резолвинга, установка,
  применение профиля, проверка MTProto по IP и домену и HTTPS. Только затем
  можно освобождать старые и отбракованные VPS.
- Если удаление отклонено, ресурс остаётся в учёте и администратор получает
  уведомление; не следует обходить ограничения бота или предполагать возврат.

## Реализованные части и граница текущего этапа

`nodehost.py` читает квитанции и список серверов, хранит доступы в зашифрованных
интеграциях, отдельную историю IP — в `SystemSetting`. Импорт не передаёт
существующие серверы под автоматическое управление. Пароли не возвращаются
в API, Telegram, результаты команд и журнал аудита.

`nodehost_orders.py` проходит проверенное меню конфигуратора и получает
предложение на сутки. Перед единственным нажатием оплаты сохраняются цена,
параметры, отпечаток меню, аккаунт, граница сообщений и операция. Предложение
действует десять минут и используется один раз. Изменение цены/параметров
останавливает действие. Неопределённый заказ блокирует следующие покупки
этого аккаунта. Повтор операции не отправляет оплату заново. Параллельный
ручной диалог во время оплаты требует сверки.
Явный ответ хостера о недостатке средств сохраняется как `DECLINED_FUNDS`,
с суммой недостачи и ID сообщения. Он не считается созданием VPS или
неопределённым заказом. Эта операция и использованное предложение не оплачиваются
повторно; после пополнения требуется новое предложение и новая операция.

Хостер иногда игнорирует первое нажатие выбора скорости в новом меню.
Для этого бесплатного шага допускается один повтор после чтения той же
неизменившейся клавиатуры. Для оплаты такой повтор запрещён.

`vps_preflight.py` реализует предпроверку нового IPv4. Веб-панель и отдельная
кнопка бота показывают импортированные VPS. Из панели доступны реальные
проверки SSH, ОС и Telemt и отдельное подтверждение покупки по точной цене.

`vps_bootstrap.py` содержит установку на явно управляемый чистый VPS в
отдельном systemd-задании. Исходник TelemtProxy закреплён по commit и SHA-256.
Его вложенные зависимости MEKO/latest пока выбираются самим установщиком;
полная воспроизводимость всего стека не подтверждена. Существующая установка
не перезаписывается. Только `general.ad_tag` и `access.users.hello` меняются
по зашифрованному профилю, с проверкой TOML, backup и откатом при ошибке запуска.
SSH использует одно явно разрешённое первичное закрепление ключа (TOFU), затем
обязательно проверяет сохранённый ключ. Пароль не передаётся через argv.

`vps_certificates.py` переносит только Certbot lineage выбранного домена,
включая разрешённые ссылки на archive и привязанный ACME account. Набор хранится
зашифрованно, проверяются SAN, срок и соответствие ключа. Установщик уже имеет
`--keep-until-expiring`, поэтому сохранённый действующий сертификат не должен
переиздаваться на каждом VPS. Живой перенос и продление ещё требуют пилота.

**Не реализован и не активирован общий автоматический цикл Node Host:**
привязка текущего сервера к логическому агенту, перенос/регистрация Agent,
устойчивый worker замены VPS, DNS-переход с откатом, подтверждённое удаление и
сверка возвратов, наследование режима следующим экземпляром и автопродление.
Существующий DNS-адаптер AutoIP остаётся общим; сценарий VPS должен отдельно
проверить его границы. Наличие функций установки не означает проверенный
живой перенос. В этой версии нет скрытой фоновой покупки VPS.

## Живой пилот 31 октября 2026

Одна согласованная покупка VPS с 1 CPU / 3 ГБ / 25 ГБ на сутки подтверждена
квитанцией хостера. Доступы сохранены зашифрованно, SSH и чистая Ubuntu 24.04
проверены с закреплением ключа сервера. Первый кандидат повторно не отвечал
по TCP 22 из обеих российских сетей Check-Host при доступности из Германии,
Нидерландов и Франции. Контрольный запрос из российской точки к другому
адресу прошёл. DNS и работающая конфигурация исходной ноды сохранены;
подмена недоступного кандидата рабочим результатом не допускается.

На отдельном купленном VPS реально восстановлен сохранённый Certbot lineage.
Временный HTTPS-сервер с полной цепочкой прошёл проверку доверенного центра
и имени выбранного домена при прямом соединении с новым IP. Отпечаток
сертификата совпал с исходным, права закрытого ключа — 0600. После проверки
временный сервер остановлен. Новый сертификат не заказывался.
Это подтверждает перенос сертификата, но не продление: для полноценного
`certbot renew --dry-run` ещё требуется подходящий кандидат и согласованный
переход домена. Полный перенос прокси и автоматическое восстановление VPS
по-прежнему не подтверждены этим пилотом.

## Команды подготовки

```sh
# Чтение истории только для явно указанных IP:
docker compose exec -T commander python -m commander.manage nodehost discover \
  --integration-id TELETHON_UUID --addresses SELECTED_PUBLIC_IPV4
# Проверки без записи на VPS:
docker compose exec -T commander python -m commander.manage nodehost status
docker compose exec -T commander python -m commander.manage nodehost inspect --receipt-id RECEIPT_ID
docker compose exec -T commander python -m commander.manage nodehost check --receipt-id RECEIPT_ID
# Только расчёт, без оплаты:
docker compose exec -T commander python -m commander.manage nodehost quote --integration-id TELETHON_UUID
# Только после отдельного разрешения владельца по показанной цене:
docker compose exec -T commander python -m commander.manage nodehost order \
  --quote-id QUOTE_UUID --operation-id OPERATION_UUID --approved
```

Профиль `telemt_profile` задаётся через защищённую панель/локальный ввод;
`domain`, `secret`, `ad_tag` не помещаются в Git. Режимы Node Host и Cherry
разделены; Cherry-адаптер отвергает агентов другого провайдера.
